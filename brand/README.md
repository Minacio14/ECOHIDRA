# ECOHIDRA — marca

Paleta: azul + verde + preto.

| Cor | Hex | Uso |
|---|---|---|
| Preto | `#0a1216` | texto, fundos escuros, palavra "ECOHIDRA" |
| Azul | `#0b6fb3` → `#31bfe8` | água, ligações, realces |
| Verde | `#1f8a4c` → `#6fd27f` | folha, botões de acção, ambiente |

Ficheiros:
- `ecohidra-mark.svg` / `.png` — só o símbolo (gota azul + folha verde), fundo transparente.
- `ecohidra-logo-vertical.png` e `-white.png` — símbolo por cima do nome (versão escura para fundos claros; branca para fundos escuros).
- `ecohidra-logo-horizontal.png` e `-white.png` — símbolo ao lado do nome.

O texto "ECOHIDRA / SOLUÇÕES AMBIENTAIS" usa Montserrat (800 e 600, espaçamento largo na linha de baixo).
